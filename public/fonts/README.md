# Bundled fonts

Lens serves every font from its own files. No font CDN is required.

| File | Family | License |
| --- | --- | --- |
| `inter-variable.woff2` | Inter | SIL Open Font License 1.1, `inter-OFL.txt` |
| `jetbrains-mono-*.woff2` | JetBrains Mono | SIL Open Font License 1.1, `jetbrains-mono-OFL.txt` |
| `grand-hotel-400.woff2` | Grand Hotel | SIL Open Font License 1.1, `grand-hotel-OFL.txt` |

The font licenses apply separately from the application MIT license. Inter supplies the interface text. JetBrains Mono supplies figures and labels. Grand Hotel supplies the wordmark.

Sources: [Inter](https://github.com/rsms/inter), [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), and [Grand Hotel](https://github.com/google/fonts/tree/main/ofl/grandhotel).
